# 🛒 쇼핑 리스트

아이템 추가·삭제·체크 기능이 있는 간단한 쇼핑 리스트 웹 앱입니다. 라이브러리 없이 HTML/CSS/JavaScript만으로 만들었습니다.

## 기능

- **추가**: 입력 후 Enter 또는 "추가" 버튼 (빈 입력은 무시, 앞뒤 공백 자동 제거)
- **체크**: 체크박스로 구매 완료 표시 (취소선)
- **삭제**: 각 항목의 ✕ 버튼
- **구매 완료 항목 지우기**: 체크된 항목을 한 번에 삭제
- **자동 저장**: `localStorage`에 저장되어 새로고침해도 유지

## 실행 방법

`index.html`을 브라우저로 열면 됩니다.

일부 브라우저는 `file://`에서 `localStorage` 저장을 막을 수 있습니다. 그럴 때는 로컬 서버로 실행하세요.

```bash
npx http-server
```

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `app.js` | 추가·삭제·체크·저장 기능 |
